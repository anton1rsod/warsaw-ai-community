# Community Platform v0.8.0 — Typography Realignment + Brand Polish — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the platform display font Fraunces → Geist (brand.md §2 compliance), re-treat the Fraunces-italic surfaces as Geist 600 (headlines) or JetBrains Mono dust (accents), pin the footer (density fix), and swap favicon/PWA icons to the amber-field S.

**Architecture:** Repoint the `font-display` Tailwind token from Fraunces → Geist (token name preserved, so 19 `font-display` usages flip automatically); per-surface edits drop `italic`/`font-black` and re-treat each line per the categorization; a `flex-1` wrapper in `RootShell` pins the footer; favicon is a byte-swap from `community/brand/exports/symbol/`. **Self-contained** — loads Geist itself; PR #41 is reconciliation, not a dependency.

**Tech Stack:** Next.js 16 (App Router), TypeScript, Tailwind CSS, `next/font/google`, Vitest + Testing Library. Tests live in `tests/unit/` (NOT co-located). Run from `projects/community-platform/`.

**Spec:** `docs/specs/2026-05-26-community-platform-v0-8-typography-ui-ux-design.md` (canonical design; §18 of `spec.md` folded in at closeout — Task 9.1).

**Color/weight contract (apply consistently):**
- Headlines/titles: `font-display` (= Geist) + `font-semibold` (600). Remove `italic`, remove `font-black`/`font-bold`.
- Accent / empty-state asides: `font-voice` (= JetBrains Mono) + `text-dust`. Remove `italic`, remove `font-display`. Size one step down from current (mono runs ~15% wider).
- Trailing **em-dash** flourish → wrap in `<span className="text-accent-500">—</span>`. Trailing **periods** stay ink (no recolor).
