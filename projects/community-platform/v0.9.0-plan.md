# Community Platform v0.9.0 Implementation Plan — Redesign completion (readers) + `dark:` landmine

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **One Sonnet implementer per phase** (not per micro-task — token discipline, per v0.8 precedent); full-suite verification at every phase boundary.

**Goal:** Apply the locked v0.6→v0.8 warm-maximalist design system to the un-redesigned reader surfaces (+`/login`) and resolve the platform-wide `dark:` Tailwind landmine, shipping a visually-consistent reader experience as v0.9.0.

**Architecture:** Phase 1 flips `darkMode` to `"selector"` (dead-codes all 74 `dark:` variants platform-wide — no `.dark` ancestor is ever rendered) and hardens the two shared primitives (`Tag`, `Pill`). Phases 2-4 re-skin reader surfaces + their components to a documented **reader-page recipe** lifted from the shipped `/events`. Phase 5 backfills functional + a11y E2E against the now-final templates. Phase 6 sweeps residual `dark:` and closes out. All surface work is **className-only** — zero rendering/logic changes.

**Tech Stack:** Next.js 16.2.6 (App Router) · React 19.2.0 · Tailwind CSS 3.4.19 · TypeScript 5.7 · Vitest 2.1 · Playwright 1.59 + @axe-core/playwright 4.11.

## Conventions & shared contracts (read once — referenced by every task)

### C1. The reader-page recipe (index/list surfaces)

Every reader index converges on this shell (verbatim from `app/events/page.tsx`):

```tsx
<main id="main" className="mx-auto max-w-3xl px-6 py-10">
  <MonoLabel>{KICKER}</MonoLabel>
  <h1 className="mt-2 font-display font-semibold text-[40px] leading-[0.95] tracking-tight text-ink">
    {TITLE}
  </h1>
  <div className="mt-3 flex flex-wrap gap-2">{/* <Pill variant="solid|dashed|going"> CTAs */}</div>

  <section aria-labelledby="SECTION-heading" className="mt-8">
    <MonoLabel>{SECTION_LABEL}</MonoLabel>
    <h2 id="SECTION-heading" className="sr-only">{SECTION_LABEL}</h2>
    {items.length === 0
      ? <EmptyState headline={…} calibration={…} />            /* or inline: <p className="mt-2 font-voice text-[12px] text-dust">…</p> */
      : <ul className="mt-2 flex flex-col gap-2">{/* <ListItem …/> or <EventCard …/> per row */}</ul>}
  </section>
</main>
```

Imports come from `@/app/components/{MonoLabel,Pill,ListItem,EventCard,EmptyState,Tag,Avatar,DateTime}`. All copy goes through `s("…")` in `@/lib/i18n/strings` (H67 — no inline UI strings; run `pnpm h67:scan` to verify).

### C2. The `.prose-warm` contract (detail/prose surfaces)

`@tailwindcss/typography` is **NOT installed** (`tailwind.config.ts` `plugins: []`), so the existing `prose prose-neutral dark:prose-invert` classes on detail pages are **no-ops** — markdown currently renders with browser defaults. `.prose-warm` (defined in Task 1.2) provides real element-level styling via `@layer components` + element selectors. Detail surfaces replace `prose prose-neutral dark:prose-invert` → `prose-warm` on the markdown container.

### C3. Token-mapping table (apply on every reskin; this is the DRY backbone)

| Scaffolding class | → Warm token | Notes |
|---|---|---|
| `text-neutral-900` | `text-ink` | primary text |
| `text-neutral-700` | `text-ink` (body) / `text-dust` (secondary) | context-dependent |
| `text-neutral-600` `text-neutral-500` `text-neutral-400` | `text-dust` | meta/secondary; pair with `font-voice` for labels |
| `bg-neutral-50` `bg-neutral-100` | `bg-cream-deep` (subtle) / `bg-paper` (card) | |
| `bg-neutral-200` (chip fill) | use `<Tag>` or `<Pill>` | don't hand-roll chips |
| `border-neutral-*` | `border-ink` (structural) or remove | |
| `rounded` `rounded-*` `rounded border` | **remove** | zero-radii posture |
| `prose prose-neutral dark:prose-invert` | `prose-warm` | C2 |
| heading text | `font-display font-semibold text-ink` | |
| kicker/section label | `<MonoLabel>` (mono uppercase dust) | |
| meta/timestamp line | `font-voice text-dust` (+ `<DateTime>` for dates) | |
| body copy | `font-body text-ink` | |
| `text-accent-*` / `bg-accent-*` | keep **only** for action / you-are-here / RSVP-going / date-badge (Q4.8) | else → dust |
| **any** `dark:*` variant | **remove** | the flip dead-codes them; strip the dead code |

### C4. Per-surface source-scan test template (H99 — one per reskinned file)

Replicates `tests/unit/projects-page.test.tsx`. For surface at `app/<path>/page.tsx`, create `tests/unit/<name>-page.test.tsx`:

```tsx
import { readFileSync } from "node:fs";
import { resolve } from "node:path";
import { describe, it, expect } from "vitest";

describe("<surface> v0.9 — warm-aesthetic, no dark:/scaffolding", () => {
  const src = readFileSync(resolve(__dirname, "../../app/<path>/page.tsx"), "utf8");

  it("uses no Tailwind `dark:` variants", () => {
    expect(src).not.toMatch(/\bdark:/);
  });
  it("uses no neutral-* / gray-* color scale", () => {
    expect(src).not.toMatch(/\b(text|bg|border)-neutral-/);
    expect(src).not.toMatch(/\b(text|bg|border)-gray-/);
  });
  it("uses no rounded-border scaffolding", () => {
    expect(src).not.toMatch(/\brounded\b/);
  });
  it("uses recipe tokens (font-display heading on cream/ink)", () => {
    expect(src).toMatch(/font-display/);
    expect(src).toMatch(/text-ink|text-dust/);
  });
});
```

Component reskins (`app/components/<C>.tsx`) get the same scan minus the recipe-token assertion (component-appropriate token assertion instead).

function classesFor(variant: TagVariant | undefined, value: string | undefined): string {
  const base = "inline-flex items-center px-2 py-0.5 font-voice text-[10px] uppercase tracking-[0.5px]";
  if (variant === "status" && value === "proposed") {
    return `${base} bg-accent-50 text-accent-700`; // O12 — sole accent variant (action-adjacent, Q4.8)

  if (variant === "status" && value === "superseded") {

    return `${base} bg-cream-deep text-dust`;
  }
  return `${base} bg-cream-deep text-ink`;
}

import { readdirSync, readFileSync, statSync } from "node:fs";
import { resolve, join } from "node:path";
import { describe, it, expect } from "vitest";

function walk(dir: string): string[] {
  return readdirSync(dir).flatMap((name) => {
    const full = join(dir, name);
    return statSync(full).isDirectory() ? walk(full) : [full];
  });
}

describe("H98: zero dark: variants remain in app/", () => {
  const appDir = resolve(__dirname, "../../app");
  const offenders = walk(appDir)
    .filter((f) => /\.(ts|tsx|css)$/.test(f))

  it("no app/ source file uses a dark: variant", () => {
    expect(offenders, `dark: still present in:\n${offenders.join("\n")}`).toEqual([]);
  });
});
